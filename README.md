
## 1. Как пушить (отправка кода на сервер)

git add .

(Точка означает «все измененные файлы». Чтобы добавить конкретный файл, укажите его имя вместо точки).

git commit -m "..."

git push origin main

(Где origin — имя удаленного репозитория, а main — название вашей ветки).

## 2. Как пулить

git pull origin main

• Скачать без слияния (только посмотреть, что нового):
git fetch origin

## 3. Остальные важные команды


Работа с ветками

• git branch — показать все локальные ветки (текущая отмечена звездочкой *).
• git switch -c new-feature — создать новую ветку new-feature и сразу перейти в нее.
• git switch main — переключиться обратно на ветку main.
• git merge new-feature — влить изменения из new-feature в ту ветку, в которой вы сейчас находитесь.

Прятки (Stash) — если нужно срочно переключиться

• git stash — временно спрятать незакоммиченные изменения и очистить рабочую директорию.
• git stash pop — вернуть спрятанные изменения обратно.

Отмена действий и просмотр истории

• git status — самая частая команда; показывает, какие файлы изменены, добавлены или удалены.
• git log --oneline — компактный список последних коммитов с их хэшами.
• git restore <файл> — отменить изменения в файле до последнего коммита.
• git reset --soft HEAD~1 — отменить последний коммит, но сохранить все изменения в файлах.
• git reset --hard HEAD~1 — полностью удалить последний коммит и стереть все изменения в нем.
